# Program 12: MongoDB Age Filtering

## Description
A Java program that retrieves all students older than 20 years from a MongoDB collection using the `$gt` operator.

## Files
- `src/main/java/FindStudents.java`: Implementation of the filtered query.
- `pom.xml`: Maven configuration with MongoDB Driver dependency.

## How to Run
1. Ensure MongoDB is running on `localhost:27017`.
2. Compile and run `FindStudents.java`.

## Expected Output
Console list of students whose age is greater than 20.
