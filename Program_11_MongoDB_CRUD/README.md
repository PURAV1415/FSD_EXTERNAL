# Program 11: MongoDB CRUD Operations

## Description
A Java program that connects to a MongoDB database and performs insertion and retrieval of student records.

## Files
- `src/main/java/StudentMongoDB.java`: Implementation of MongoDB operations.
- `pom.xml`: Maven configuration with MongoDB Driver dependency.

## How to Run
1. Ensure MongoDB is running on `localhost:27017`.
2. Compile and run `StudentMongoDB.java`.

## Expected Output
Console: "Student inserted successfully!" followed by the list of all students in the `students` collection.
