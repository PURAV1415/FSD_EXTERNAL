# Program 7: JDBC Data Retrieval

## Description
A Java program that connects to a MySQL database (`college`) and retrieves all records from the `students` table.

## Files
- `src/main/java/RetrieveData.java`: Java logic for JDBC connection and retrieval.
- `pom.xml`: Maven configuration with MySQL Connector/J dependency.

## How to Run
1. Ensure MySQL is running and the `college` database with `students` table exists.
2. Compile and run `RetrieveData.java` using Maven or an IDE.

## Expected Output
Console output displaying student IDs, names, and emails.
