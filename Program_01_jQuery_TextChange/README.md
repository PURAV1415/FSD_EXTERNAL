# Program 1: jQuery Text Change

## Description
A simple jQuery program that changes the text of a paragraph when a button is clicked.

## Files
- `index.html`: Contains the HTML structure and jQuery logic.

## How to Run
1. Open `index.html` in any modern web browser.
2. Click the "Click Me" button.

## Expected Output
- **Initial State**: "This is the original text."
- **After Click**: "The text has been changed!"
