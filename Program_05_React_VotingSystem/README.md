# Program 5: ReactJS Voting Application

## Description
A voting application using ReactJS that tracks votes for three candidates and displays the total count dynamically.

## Files
- `src/App.jsx`: Main application logic and styling.
- `src/main.jsx`: React entry point.
- `index.html`: HTML host.
- `package.json`: Dependencies.

## How to Run
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Cast votes for candidates.

## Expected Output
- Voting interface for Candidate A, B, and C.
- Real-time update of individual candidate votes and total votes.
- A confirmation message when a vote is recorded.
