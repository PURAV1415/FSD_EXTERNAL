# Program 3: Basic Calculator in ReactJS

## Description
A basic calculator application using ReactJS `useState` to perform addition, subtraction, multiplication, and division.

## Files
- `src/App.jsx`: Main logic for the calculator.
- `src/main.jsx`: React entry point.
- `index.html`: HTML host.
- `package.json`: Dependencies.

## How to Run
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Open the browser and perform arithmetic operations.

## Expected Output
- Two input fields for numbers.
- Four buttons (+, -, *, /).
- A result display that updates dynamically.
- Error message "Cannot divide by zero" when dividing by 0.
