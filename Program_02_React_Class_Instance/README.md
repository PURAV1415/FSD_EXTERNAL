# Program 2: ReactJS Class and Instance

## Description
Demonstrates the use of a standard JavaScript Class and its instances within a React application to display student details.

## Files
- `src/App.jsx`: Contains the `Student` class and the `App` component.
- `src/main.jsx`: Entry point for the React application.
- `index.html`: Root HTML file.
- `package.json`: Project dependencies.

## How to Run
1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open the provided URL in the browser.

## Expected Output
- Heading: "ReactJS Class and Instance"
- Paragraph 1: "Madhu is learning ReactJS"
- Paragraph 2: "Ravi is learning Java"
