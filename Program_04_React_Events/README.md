# Program 4: ReactJS Event Handling

## Description
Demonstrates common event handling in ReactJS including `onClick`, `onMouseOver`, `onChange`, and `onSubmit`.

## Files
- `src/App.jsx`: Implementation of the events and the styled UI.
- `src/main.jsx`: React entry point.
- `index.html`: HTML host.
- `package.json`: Dependencies.

## How to Run
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Interact with the buttons, inputs, and form.

## Expected Output
- Dynamic updates of the "EVENT RESULT" message based on the triggered event.
